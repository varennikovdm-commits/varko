# varko

Telegram-бот с погодой и мини-приложением кликера.

## Возможности
- Кнопки выбора города и получение текущей погоды через API Яндекс Погоды.
- Команда `/clicker`, которая открывает мини-приложение «Солнечный кликер» прямо внутри Telegram.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Переменные окружения

Создайте файл `.env` в корне проекта и добавьте ключи:

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_бота
YANDEX_WEATHER_KEY=ваш_ключ_яндекс_погоды
```

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота (по умолчанию используется токен из задания).
- `YANDEX_WEATHER_KEY` — ключ API Яндекс Погоды (по умолчанию используется ключ из задания).
- `CLICKER_URL` — публичный HTTPS URL мини-приложения (по умолчанию `http://localhost:8000`).
  Чтобы мини-апп открывался у всех пользователей в Telegram, разместите его на публичном домене.

## Запуск

1. Установите зависимости (см. раздел выше).
2. Убедитесь, что в `.env` лежат значения `TELEGRAM_BOT_TOKEN` и `YANDEX_WEATHER_KEY`.
3. Запустите веб-приложение и бота.

### Мини-приложение

```bash
python webapp/app.py
```

### Бот

```bash
python bot.py
```

После запуска используйте `/start` для выбора города и `/clicker` для открытия мини-приложения.

## Как подключить мини-апп в Telegram для всех пользователей

1. Разверните мини-приложение на публичном HTTPS домене (например, Render, Railway, VPS).
2. Укажите адрес в переменной `CLICKER_URL`.
3. В настройках бота через BotFather проверьте, что Web App разрешен (Menu Button).
4. После этого любому пользователю будет доступно открытие мини-аппа из бота.
