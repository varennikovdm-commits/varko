# Солнечная Ферма

Проект состоит из двух независимых частей: Telegram-бота и мини-приложения (Mini App).

## 1. Telegram-бот (Python, aiogram 3.x)

### Возможности
- Главное меню с кнопками:
  - ☀️ Погода по городам (список с пагинацией + поиск).
  - ⚡️ Запустить Солнечный Кликер (WebApp кнопка на ваш Mini App).
- Прогноз погоды: текущие условия + 3 дня вперед через API Яндекс.Погоды.
- Поллинг (long polling), подходит для запуска на локальном ПК.

### Настройка
1. Перейдите в папку `bot`.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните переменные:
   - `BOT_TOKEN`
   - `YANDEX_API_KEY`
   - `MINI_APP_URL`
4. Запуск:
   ```bash
   python main.py
   ```

## 2. Mini App (HTML/CSS/JS)

### Возможности
- Кликер «Солнце» с анимацией пульсации и вспышкой при клике.
- Счетчик энергии, уровни, прогресс-бар.
- Магазин улучшений (клик-сила, автокликер, солнечные фермы).
- Прогресс сохраняется в `localStorage`.
- Темная тема и оранжевые акценты, адаптация под мобильные устройства.

### Размещение
Содержимое находится в папке `mini_app`. Разместите файлы на вашем VPS и откройте `index.html`.
